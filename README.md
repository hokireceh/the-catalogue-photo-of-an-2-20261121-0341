A catalogue photograph of an impossible gadget: the RockCharge, a wireless charger for a river stone. A speckled stone sits mid-charge on a matte black pad, a green charge ring glowing beneath it, one cable snaking away to a USB-C plug. The whole picture is drawn by the program itself — a small rasterizer, a pure PNG encoder, and a hand-written bitmap font — no photos, no downloaded assets.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Writes `/tmp/out/entry.png` (1024×1024 PNG, about 58 KB) and exits.
